# Security

This initial release has no independent security audit or production support guarantee. Use a patched Python in an isolated worker with external CPU and memory limits for untrusted artifacts. See the threat model before adoption.

For a suspected vulnerability, use GitHub's private vulnerability reporting if available on this repository. If it is unavailable, request a private reporting channel in an issue without publishing sensitive details or working exploits. Report ordinary policy false positives as normal issues with synthetic examples.
